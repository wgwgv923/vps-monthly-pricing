### 留意“假月付”：多年合约价伪装成月价

还有一类坑要单独说：有些商家把多年合约的均价标成“月付价”。比如 Hostinger 的 4GB KVM 套餐标着 $6.49/月，这个价格对应的是 24 个月合约期，下单时一次要付一百五十多美元。看到任何“$X/月”的标价，先确认它是每月扣一次，还是 12 个月、24 个月一次付清——这两种“月付”完全是两回事。

## 下单前后最容易踩的五个坑

下单环节的问题集中在支付和续费两处，下面五个各家通用，买搬瓦工同样适用：

1. 别挂代理或机场下单。主机商风控会把代理 IP 下单判为欺诈（Fraud），机器可能直接被取消，家用网络直连最稳。
2. PayPal 结算时选“银行汇率”。默认的 PayPal 汇率换汇损耗大，改成银行汇率结算，每 20 美元能省十多块人民币。
3. 付完款去 PayPal 设置里取消自动续费。不少商家默认开启，忘了取消第二年自动扣款，事后申请退款比事前取消麻烦得多。
4. 能走 PayPal 就走 PayPal。支付宝付款方便，但遇到商家跑路，PayPal 有争议退款的可能，支付宝相对缺少这类救济渠道。搬瓦工两家都支持，优先 PayPal。
5. 月付价先看合约期，年付先算月均。确认标价是每月扣一次还是多年一次付清；年付方案用总价除以 12 算月均，再和真月付方案对比，答案通常自己就出来了。
